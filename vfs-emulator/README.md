# Эмулятор командной строки (Вариант 22, Этап 1)

Минимальный прототип эмулятора оболочки с графическим интерфейсом (GUI).

## Общее описание
Приложение представляет собой прототип графического эмулятора командной строки UNIX-подобной ОС, реализованный на языке Java (Swing). Поддерживает интерактивный ввод команд (REPL), раскрытие системных переменных окружения, команды-заглушки и корректное завершение работы.

## Настройки и функции
- **Формирование заголовка окна:** заголовок генерируется динамически на основе текущего пользователя и имени хоста ОС в формате `Эмулятор [username@hostname]`.
- **Парсер аргументов:** поддерживает подстановку значений переменных окружения вида `$VAR` (например, `$USERNAME`, `$USER`, `$COMPUTERNAME`).
- **Команды-заглушки:**
  - `ls [аргументы]` — выводит имя команды и переданные аргументы.
  - `cd [аргументы]` — выводит имя команды и переданный целевой путь.
- **Команда выхода:**
  - `exit` — завершает выполнение программы и закрывает окно.
