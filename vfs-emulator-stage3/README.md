# Эмулятор оболочки ОС — Этап 3 (Вариант №22)

## Описание
Проект представляет собой прототип графического эмулятора командной строки UNIX-подобной ОС на языке Java (Swing).
В рамках Этапа 3 реализовано подключение виртуальной файловой системы (VFS) на основе XML-файла с хранением структуры исключительно в оперативной памяти.

## Функционал Этапов 1–3
1. **GUI интерфейс**: окно Swing с динамическим заголовком вида `Эмулятор [username@hostname]`.
2. **Парсер аргументов**: поддержка кавычек для аргументов с пробелами и раскрытия системных переменных окружения (`$HOME`, `$USER`).
3. **Заглушки команд**: `ls`, `cd`, `exit`.
4. **Конфигурация (CLI)**:
   - `--vfs <путь к XML>`
   - `--script <путь к стартовому скрипту>`
   - Отладочный вывод заданных параметров при запуске.
   - Остановка стартового скрипта при первой ошибке с имитацией ввода-вывода.
5. **VFS в памяти**:
   - Чтение и парсинг XML-файла.
   - Поддержка двоичных файлов через `base64`.
   - Запрет на распаковку на диск — всё дерево хранится в памяти.
   - 3 тестовые VFS: минимальная, набор файлов, дерево глубиной от 3 уровней.

## Сборка и запуск
- Запуск по умолчанию:
  - Windows: `run.bat`
  - Linux/macOS: `./run.sh`
- Прогон всех тестовых сценариев параметров CLI и вариантов VFS:
  - Windows: `test_cli.bat`
  - Linux/macOS: `./test_cli.sh`
